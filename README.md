# MaximUM massage

Информационный сайт кабинета ручного массажа в Чебоксарах.

Постоянный адрес: https://maximummassage.github.io/
GitHub Pages: ветка main, корневая папка. Без сборки, регистрации и базы данных.

Услуги, цены и ссылки изменяются в content.js. Структура — index.html, оформление — styles.css и motion.css, поведение — app.js. Обновление файлов не меняет адрес сайта.

Montserrat, Manrope и Oswald — локальные шрифты; лицензии SIL OFL. Иконки Lucide — ISC. Фотографии и тексты MaximUM massage не предназначены для использования от имени других специалистов. Логотипы сервисов принадлежат их владельцам.
