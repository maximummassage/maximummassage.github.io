# MaximUM massage

Информационный сайт кабинета ручного массажа в Чебоксарах.

Чистые HTML, CSS и JavaScript, локальные фотографии, шрифт и логотипы. Без сборки, регистрации и базы данных.

## Обновление

Услуги, стоимость, описания и ссылки находятся в `content.js`. Оформление — в `styles.css` и `motion.css`; структура страницы — в `index.html`.
Изменения этих файлов не меняют адрес сайта. GitHub Pages настроен на ветку `main`, корневую папку.

Фотографии и тексты MaximUM massage не предназначены для использования от имени других специалистов.
Названия и логотипы сервисов принадлежат их владельцам.
